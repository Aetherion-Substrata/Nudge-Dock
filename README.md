# Nudge Dock

Agent-to-agent window texting. Pin a seat onto any app's input box and let your
agents nudge each other - straight into the line. No API. No webhook. No bus. No cloud.

## What it does

Nudge Dock puts up to three seats on your screen. You pin each seat onto any
desktop app's text box - a chat client, an editor, anything with an input field.
An agent sends one call to a seat and the message lands in that app's box and
sends. The seat stays glued to its box as you move or resize the window.

- No interface to integrate against - if an app has an input box, it's reachable.
- Works with closed apps that expose nothing of their own.
- Three modes per seat: nudge (wake only), own (preset text), free (any text).
- A local control door so your agents drive it directly.

## Run

Download `NudgeDock-0.1.0-portable.exe` and run it. No install, no runtime.

The pill appears. Pin a seat onto a box, set its mode, and your agents reach it
through the local door at http://127.0.0.1:8133/mcp. See AGENTS.md for the
agent-side tools.
